# Pédagogie du skill — darija algérienne

## Objectif

Faire progresser l’apprenant vers une communication réelle, pas seulement vers la mémorisation de listes.

## Principes

1. **Oral d’abord** : écouter, répéter, parler.
2. **Phrases utiles** : enseigner des expressions réutilisables.
3. **Situations concrètes** : marché, taxi, téléphone, famille, travail.
4. **Grammaire appliquée** : expliquer une règle à partir d’exemples.
5. **Culture** : ajouter une note culturelle quand elle aide à comprendre.
6. **Répétition espacée** : faire revenir les mots déjà vus.
7. **Encouragement** : débloquer la peur de parler.
8. **Prudence** : signaler les variations et les incertitudes.

## Format d’une mini-leçon

```text
Titre
Objectif en une phrase
Niveau
Durée estimée

1. Écoute / découverte
   - 3 à 5 expressions
   - arabe + phonétique + français

2. Explication simple
   - une règle maximum
   - exemples

3. Dialogue court
   - 4 à 8 répliques
   - contexte réel

4. Exercice
   - 3 à 5 questions
   - correction

5. Révision
   - 2 mots anciens
   - 1 phrase à réutiliser

6. Note culturelle optionnelle
```

## Format d’un dialogue

```text
Contexte : au marché
Personnages : client, vendeur
Niveau : débutant

Client : Salam, bchhal hada?
Vendeur : B miyat dinar.
Client : Ghali bezaf!
Vendeur : Wach tseb?
Client : Nbghi rkhiss chwiya.

Traduction :
...

Points langue :
- bchhal = combien
- ghali = cher
- bezzaf = beaucoup
- chwiya = un peu
```

## Format d’un quiz

Types de questions :

1. traduction français → darija ;
2. traduction darija → français ;
3. choix multiple ;
4. compléter une phrase ;
5. remettre un dialogue dans l’ordre ;
6. choisir la forme négative ;
7. choisir la forme féminine/masculine ;
8. écouter un audio si disponible.

Toujours fournir :

- la réponse correcte ;
- une explication courte ;
- une phrase exemple.

## Correction de production apprenant

Quand l’apprenant écrit une phrase :

1. Dire si c’est compréhensible.
2. Corriger doucement.
3. Donner une version naturelle.
4. Expliquer une seule erreur principale.
5. Proposer une variante plus simple si nécessaire.

Exemple :

```text
Apprenant : ana nruh souq
Compréhensible : oui.
Version naturelle : ana nruh l souq.
Explication : on ajoute souvent “l” pour indiquer la direction.
```

## Adaptation au niveau

### Débutant

- phrases courtes ;
- beaucoup de phonétique ;
- traduction systématique ;
- pas de métalangage complexe.

### Intermédiaire

- dialogues plus longs ;
- négation, futur, questions ;
- moins de traduction mot à mot.

### Avancé

- expressions idiomatiques ;
- variations régionales ;
- humour, proverbes, culture ;
- production libre.

## Adaptation au public

- Diaspora : famille, racines, comprendre les parents/grands-parents.
- Voyageurs : transport, achats, urgences, politesse.
- Professionnels : téléphone, rendez-vous, clients, service.
- Créateurs : scripts, voix off, publicités, sous-titres.

## Audio

Si aucun audio natif n’est fourni :

```text
Ne pas prétendre qu’un son est natif.
Indiquer : “audio à enregistrer par un locuteur natif”.
```

Si un audio est fourni :

```text
Vérifier droits, consentement, qualité, transcription.
```

## Évaluation rapide

Un bon contenu darija doit être :

- compréhensible par un Algérien ;
- naturel à l’oral ;
- utile dans une situation réelle ;
- accompagné d’une phonétique cohérente ;
- non confondu avec du MSA ou du marocain ;
- culturellement respectueux ;
- réutilisable dans l’application.
