# Règles linguistiques de base — darija algérienne

> Ces règles sont des repères pédagogiques. La darija varie par région, génération et contexte.
> En cas de doute, signaler l’incertitude et proposer une forme courante plutôt qu’une règle absolue.

## 1. Ne pas confondre les langues

- **Darija algérienne** : oral quotidien, famille, rue, travail, marché.
- **Arabe standard / MSA** : écrit formel, médias, administration, religieux.
- **Darija marocaine / tunisienne** : proches mais différentes.
- **Tamazight** : langues berbères d’Algérie, à ne pas assimiler à la darija.

Par défaut, produire de la **darija algérienne**, pas du MSA déguisé.

## 2. Convention de translittération

Utiliser une phonétique latine simple et cohérente :

| Symbole | Son approximatif | Exemple |
|---|---|---|
| 3 | ع | 3lach = pourquoi |
| 7 | ح | 7aja = chose |
| kh | خ | khobz = pain |
| gh | غ | ghali = cher |
| q | ق | qahwa = café ; peut être prononcé g selon région |
| ch | ش | chhal = combien |
| dh | ذ / ظ selon mots | souvent z/d selon région |

Toujours fournir idéalement :

```text
Arabe : ...
Phonétique : ...
Français : ...
```

## 6. Négation

Forme très fréquente :

```text
ma + verbe + ch
```

Exemples :

| Affirmatif | Négatif | Français |
|---|---|---|
| nruh | ma nruhch | je ne vais pas |
| nahder | ma nahderch | je ne parle pas |
| nbghi | ma nbghich | je ne veux pas |
| nafham | ma nafhamch | je ne comprends pas |
| 3andi | ma 3andich | je n’ai pas |

Pour l’impératif :

```text
ma + impératif + ch
```

Exemple :

```text
ma truhch = ne va pas
```

## 7. Futur proche / intention

Formes courantes :

```text
rah / rayeh / rayha / rayhin + verbe
```

Exemples :

```text
rayeh nruh = je vais aller / je compte aller
rayha nruh = je vais aller, si la personne est féminine
rayhin nruhu = nous allons aller
```

Ne pas traduire automatiquement par le futur français dans tous les cas : le contexte peut indiquer intention, mouvement ou futur proche.

## 8. Progressif / être en train de

Formes fréquentes :

```text
rani / rak / rah / raha / rana / rakum / rahum + verbe
```

Exemples :

```text
rani nahder = je suis en train de parler
rak tahder = tu es en train de parler
rah yahder = il est en train de parler
```

## 11. Accord et pluriel

Les adjectifs s’accordent souvent :

```text
kbir / kbira = grand / grande
sghir / sghira = petit / petite
jdid / jdida = nouveau / nouvelle
ghali / ghalia = cher / chère
```

Pluriels fréquents :

- -in : musulman / musulmin ? à vérifier selon mot ; ne pas généraliser aveuglément.
- -at : certaines formes féminines ou emprunts.
- pluriels internes : dar → dyur, rajel → rjal, mra → nsa.

Ne pas inventer un pluriel si incertain.

## 12. Emprunts français

La darija algérienne utilise beaucoup de mots français, surtout pour :

- téléphone ;
- administration ;
- travail ;
- école ;
- technique ;
- commerce.

Exemples courants :

```text
portable, téléphone, rendez-vous, service, dossier, facture, internet, message
```

Le skill doit accepter le code-switching naturel, mais ne pas remplacer toute la darija par du français.

## 13. Variations régionales

Par défaut, utiliser des formes largement comprises.

Signaler si une forme est régionale :

- Alger ;
- Oran / Ouest ;
- Constantine / Est ;
- Sud.

Ne pas présenter une variante locale comme “la seule vraie darija”.

## 15. Phrases de survie

```text
Ma fhemtch. = Je n’ai pas compris.
3awed men fadlek. = Répète s’il te plaît.
Hder bchwiya. = Parle lentement.
Wach t9oul? = Que dis-tu ?
Nbghi nruh l... = Je veux aller à...
Bchhal hada? = Combien ça coûte ?
Win rah...? = Où est... ?
Ma 3andich. = Je n’ai pas.
```

## 16. Ce qu’il faut éviter

- Mélanger darija algérienne et marocaine sans le dire.
- Écrire en MSA puis prétendre que c’est de la darija.
- Inventer des expressions “authentiques”.
- Utiliser des proverbes offensants sans contexte.
- Donner des conseils médicaux/juridiques comme si la traduction était une validation professionnelle.
- Prétendre qu’une translittération est une prononciation exacte universelle.
