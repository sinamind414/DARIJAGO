DarijaPro : clone fonctionnel pédagogique

Ce prototype reproduit les mécaniques génériques observées dans l’application de référence : théorie, flashcards audio, dialogue, quiz, progression et premium. Il n’utilise pas ses textes, audio, images ou son identité exacte.

  • Accueil → module → leçon
  • Théorie courte
  • Cartes : arabe + phonétique + traduction masquée
  • Dialogue avec vocabulaire coloré
  • Quiz à choix multiples
  • Score, étoiles, rappels, premium
Les boutons audio sont des emplacements : les vrais enregistrements natifs devront être produits et validés avant publication.
