## Tournures récurrentes (à valider)
- Nouvelles : `wâš kâyen yâ-Habîb ?`, `wâš râk / râk-ši blâ-hedma ?` ; réponse `râni b-hér`, `el-hamdu-llâh`, `lâ-bâs`.
- Travail : `wén tehdem derwaq ?`, `maemel / uzin` (usine), `el-hedma`, `ujra` (salaire), `blâ-hedma` (sans travail).
- Argent / prix : `b-rabe-âlâf` (quatre mille), `šrit`, `nesri`, `swâlem`, `msâréf` (frais), `ihallsu-k` (on te rembourse).
- Administration : `mekteb-el-bitâla` (bureau du chômage), `et-caewêd` (allocations), `warqa / bwâyeq` (papiers), `bitâgat-et-tacrif`.
- But / obligation : `bâš` + inaccompli ; `lâ-budda` ; `ilzem`.
- Retour / voyage : `rjea`, `sâfer`, `šart-el-bhar` (bord de mer), `el-blâd` (le pays natal).
