## Transcription du manuel

Le manuel utilise une transcription phonétique latine simplifiée :

- `â`, `û`, `î` : voyelles longues ;
- `e` : voyelle neutre articulée, non muette ;
- `š` : ch ;
- `g` : souvent q rural/g dur ;
- `e` initial peut noter ع dans la transcription du livre ;
- mots étrangers entre crochets ;
- noms propres de personnes en majuscule.

Ne pas convertir automatiquement vers `3/7/ch` sans validation.

## Règles grammaticales à retenir

### Article

```text
el- = le/la/l’
le- / la- devant certains groupes consonantiques
assimilation : ed-dâr, er-râjel, eš-šems
```

### Annexion

```text
weld-Mohammed = le garçon de Mohammed
câsémat-el-jazâir = la capitale de l’Algérie
```

### Démonstratifs

```text
hâda = celui-ci
hâdi = celle-ci
hâdu = ceux/celles-ci
hâdak = celui-là
hâdik = celle-là
hâduk = ceux/celles-là
hâd-el- + nom avec article = ce/cette…-ci
```

### Interrogation

```text
wâš = quoi / que / est-ce que
škûn = qui
kéf / kéfâš = comment
wén = où
weqtaš = quand
šhâl = combien
elaš = pourquoi
mnayn = d’où
```

### Être au présent

Proposition sans verbe fréquente :

```text
hâda, fellâh = celui-ci est cultivateur
Fâtéma, sgêra = Fatma est jeune
```

Avec pronom ou localisation/existence :

```text
râni = je suis
râk = tu es
râki = tu es (f.)
râh = il est
râha = elle est
râna = nous sommes
râkum = vous êtes
râhum = ils/elles sont
```

### Possession

```text
eand-i dâr = j’ai une maison
eand-o weld = il a un garçon
```

Possession ou matière :

```text
ed-dâr mtâe bû-ya = la maison de mon père
el-ktâb dyâl-i = le livre à moi
zerbîya mtâe es-sôf = un tapis de laine
```

### Pronoms suffixes

```text
-i = mon/ma/moi
-k = ton/ta/toi
-o = son/sa/lui
-ha = son/sa/elle
-na = notre/nous
-kum = votre/vous
-hum = leur/eux
```

### Négation

```text
ma + verbe + ši / š
ma kteb-ši = il n’a pas écrit
ma-ši farhân = pas content
```

### Accompli

Suffixes de personne ; passé :

```text
kteb = il a écrit
ketbet = elle a écrit
ktebna = nous avons écrit
```

### Inaccompli

Préfixes de personne ; présent/futur :

```text
nekteb = j’écris / j’écrirai
tekteb = tu écris
ikteb / yekteb = il écrit
iketbu = ils écrivent
```

### kân / ikûn

```text
kân = il était
kânu = ils étaient
ikûn = il sera
ikûnu = ils seront
```

### Participes

```text
eâlem = savant
sâken = habitant
gâced = assis
mabrûk = béni
mektûb = écrit
mahfûd = protégé / su par cœur
```

### Nombres 1–10

```text
wâhed / wâhda = un / une
zûj = deux
tlâta = trois
rabea = quatre
hemsa = cinq
setta = six
sebea = sept
tmânya = huit
tesca = neuf
eašra = dix
```

État construit devant nom :

```text
wâhd-el-weld = un garçon
telt-e-byût = trois pièces
hems-e-snîn = cinq ans
sebea kilu = sept kilos
```

### Jours

```text
el-hâd = dimanche
le-tnin = lundi
et-tlâta = mardi
la-rbae = mercredi
le-hmis = jeudi
el-jemca = vendredi
es-sebt = samedi
```
