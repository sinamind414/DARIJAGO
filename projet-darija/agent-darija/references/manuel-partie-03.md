## Ce que l'agent peut enseigner avec cette partie

### Temps et aspects (§113-115bis)
- Accompli = passé composé / passé simple (action achevée) ou présent pour un état ressenti : `rkbet el-qitâr`, `ana fraht`.
- Inaccompli = présent / futur : `nerkeb el-bâhira`. Après `belli, hetta, bâš, ida, lâkân` → mode français selon contexte.
- Impératif = ordre / conseil : `arkeb w-arwah`.
- Temps composés : `kân` accompli + inaccompli = imparfait (`kân igûl-li`) ; `kân` accompli + accompli = plus-que-parfait (`kân fham-ni`) ; `ikûn` inaccompli + accompli = futur antérieur (`ikûn kteb-li`). Duratif : `râni/râk…` + inaccompli (`râh ihdem`).
- Accompli + inaccompli juxtaposés : le 2e = infinitif (`bda yanzor li`).

### Verbes à conjugaison particulière (§118-125)
- **Concave** (voyelle au milieu) : `gâl, igûl` ; `bâe, ibîe` ; `hâf, ihâf`. Accompli 1re/2e pers. = voyelle brève (`gult, bict`). Participe actif en `-y-` : `râyeh, fâyeh` ; dérivés en `-w-` : `dawwar`.
- **Défectueux** (voyelle finale) : `bda, ibda` ; `mša, imši` ; `ja, iji`. Accompli 1re/2e pers. en `-i` (`bdit, mšit`) ; 3e pl. en `-aw` (`bdaw, mšaw`). Impératif `bda, bdi, bdaw`. Participe en `-i` : `gâli, zâhi`. `kla (yakul)`, `hda (yahud)` : défectueux à l'accompli, ordinaires à l'inaccompli.
- **Sourd** (2e consonne redoublée) : `habb, ihabb` ; `madd, imadd`. Accompli 1re/2e pers. dédoublé (`habbit, habbina`).

### Verbes dérivés (§128-136bis)
- Ire forme = verbe primitif. Dérivés = addition de consonnes / voyelles longues.
- **Actives** : IIe (redoublement, factitive/causative/intensive) `earraf, tawwal, fetteš, sellem, hassan` ; nom d'action `taerif, tafftîš`. IIIe (â après 1re consonne, participative) `bâyes, eâwen, râfeq` ; nom d'action `mucâwana`.
- **Réfléchies** : Ve (t- + IIe) `tkassar, tharrak, tnaqqal` (nom d'action `tafarruq`) ; VIe (t- + IIIe, réciprocité) `teâwen, tdârab` (`tacâwun`) ; VIIIe (t- infixé, profit à soi) `štġal, stka` (`štiġâl`) ; Xe (st(a)-, réfléchi ou recherche) `stiejab, stġfar`. IVe active peu apparente : `aetâ`.
- **Passives** : VIIe (n- + primitif d'action) `njrah, ngsam` (`nqisâm`) ; IXe (â avant dernière radicale, état/couleur) `šeâb, ḥdâr`. Ve peut être passif : `twelled`.
- Participes des dérivés en `m-` (me/mu) : `mrabbi, mġaṭṭi, mustašfa`.

### Infinitif (§138)
- Pas d'infinitif en arabe. 1) inaccompli après le verbe principal, sans conjonction si sentiment/désir/volonté/pouvoir/commencement (`bda igsil, nhabb neleab`), sinon `bâš` souvent supprimable (`hrej bâš idarbo la-hwâ`). 2) nom d'action/état (`nhabb er-rqâd`, `neštġal bi-tacallum el-luga`).

### Passif et « on » (§142)
- Passif rare (agent inconnu) : VIIe forme (`nhallu l-bibân`), Ve/VIe réfléchies à sens passif (`tbârek allâh`), ou `t-` préfixé à l'inaccompli (`el-ġâleb yutġlab`). Ne pas confondre `nhallu` (passif) / `nhall` (actif).
- « on » = 1re pl. (`nleabu`), 3e pl. (`demmru-ni`), passif, ou sujet vague `en-nâs` (`en-nâs eayyṭu`).

## Formules de politesse / religieuses rencontrées
- `allâh ieâwnek` (que Dieu t'aide) ; réponse `irham wâldik`.
- `allâh irahmo / irhamha` (sur un défunt / une défunte).
- `allâh itawwal eamrek` (merci) ; `bârak allâho fik` (admiration / gratitude) ; réponse `ibârek fik`.
- `eid-kum mabrûk` (bonne fête) ; réponse `tbârek fik / ibârek fik`.
- `bqa ela-hér !` (au revoir) ; `fi-gard-ek` (à ton aise, prends ton temps).
