# Enrichissement skill — partie 03

## Couverture

La partie 03 couvre environ **CON → ÊTRE**, pages imprimées 113 à 202.

## Apports principaux

### État personnel

Formes historiques relevées :

```text
rani
rak
rahi
rana
rakum
rahum
```

Usage : dire “je suis / tu es / il est / elle est / nous sommes / vous êtes / ils sont” dans un état.

Statut : `needs_native_review`.

### Futur de être

```text
nkoun = je serai
tkoun = tu seras
```

À croiser avec les formes modernes régionales.

### Possession

Historique :

```text
nitaâi
mtaâ
```

Proposition moderne à valider :

```text
nta3i
nta3
```

Ne pas imposer une seule forme sans validation.

### Démonstratifs

```text
hada = ceci / ce, masculin
hadi = cette, féminin
```

Très fréquent, mais vérifier orthographe et usage moderne.

### Interrogatif

Historique :

```text
achmen jiha = de quel côté
```

Proposition moderne :

```text
achmen jiha
wach men jiha
```

## Règles agent

- Ne jamais présenter une forme OCR brute comme forme moderne validée.
- Si une entrée a le flag `suspect_headword`, demander vérification de la page image.
- Si une entrée a `weak_entry_evidence`, ne pas générer de leçon automatique sans revue.
- Pour l’application, n’utiliser que les entrées `app_ready`.
