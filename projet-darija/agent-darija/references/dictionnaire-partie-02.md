# Enrichissement skill — partie 02

## Apports principaux

La partie 02 couvre environ ANN → CON. Elle apporte des entrées utiles pour la conversation quotidienne.

## Règles à utiliser avec prudence

### Possession

Source historique :

```text
eddar diali / eddar mtâî
```

Proposition moderne à valider :

```text
ddar dyali / ddar diali
```

Ne pas imposer une seule forme : les usages varient.

### Avec

La source donne des formes collées pour “avec moi / avec toi / avec lui”.

Proposition moderne :

```text
m3aya
m3ak
m3ah
m3aha
m3ana
m3akum
m3ahum
```

### Demander le nom

Historique :

```text
kach issemmouk
```

Proposition moderne :

```text
wach ismek ?
kifach ismek ?
```

### Apporter

Formes relevées :

```text
nejib
jebt
jab
jib
jibi
jibou
```

Exemple original :

```text
jib li ma = apporte-moi de l’eau
```

### Bon appétit

Formule historique :

```text
Allah iqennâak
```

À traiter comme formule culturelle, pas comme seule forme moderne universelle.

## Statut

Toutes ces règles sont `needs_native_review`.
