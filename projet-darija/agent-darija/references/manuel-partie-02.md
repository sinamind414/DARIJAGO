## Ce que l'agent peut enseigner avec cette partie

### Verbe
- **Impératif** (§56) : 2es personnes seulement, obtenu en retirant le préfixe `t-` de l'inaccompli.
  `kteb` (écris, m.), `ketbi` (f.), `ketbu` (pl.) ; voyelle-préfixe parfois : `arwah` (viens), `agra` (lis).
- **Impératif 1re pluriel / interdiction** (§56bis) : `ayya-` ou `yâ-lâh` + inaccompli → `ayya-nektbu` (écrivons) ;
  `lâ-` + inaccompli + `-š` → `lâ-tketbu-š` (n'écrivez pas). Parfois `ma-`.
- **Négation complète** (§106) : `ma-… ši / šay / gêr / hetta / hetta-ši / hetta-hâd / illa` ;
  `lâ-… u-là-` (ni… ni…) ; isolée `lâ` (non) / `wâh`, `yêh`, `aywâ`, `neam` (oui).

### Nom
- **Genre** (§59, 59bis) : féminins en `-a/-â` ; êtres féminins ; parties doubles du corps (`yedd`, `eayn`, `rjel`),
  lieux (`dâr`, `blâd`, `hânût`, `el-jazâir`), feu/magie (`eš-šems`, `en-nâr`, `er-rîh`, `el-harb`).
  `-a` → `-et/-t` en annexion : `bagret-el-fellâh`, `bgart-i`.
- **Catégories de substantifs** (§64, 64bis) : noms concrets `CeCeC` ; artisans `CaCCâC` ou `-î` ;
  lieux/temps/instruments `me-`/`ma-` (`mekteb`, `mathana`, `maemel`) ; engins = artisan au féminin (`sayyâra`) ;
  noms d'action `-e-…-a` (`ktâba`, `drâfa`, `flâha`).
- **Nombre** (§74) : duel `-în` (§76, parfois `-ayn`) sur parties doubles, durées, mesures, « fois » ;
  pluriel externe `-în`, `-a`, `-ât` (§77, 77bis) ; pluriel interne (§79, 79bis, 79ter) :
  `bgâl`, `shâb`, `bnât`, `mdâres`, `dyâr`, `byût`, `ulâd`, `kbâr`, `ktüb`, `hmîr`, `hodar`, `tujjâr`, `eummâl`.
- **Collectif** (§81) : avec nom d'unité en `-a` → souvent masculin (`eš-šjar` / `šajra`) ;
  sans nom d'unité de même racine → toujours féminin (`le-gnem`, `en-nsâ`, `en-nâs`).

### Adjectif
- Catégories (§69, 69bis) : `jdid`, `mtîn` ; état `-ân` (`farhân`, `kaslân`) ; intensité `CaCCâC` (`keddâb`) ;
  origine `-î` (`jazâiri`, `bahri`) ; couleurs `hmar`, `hdar`, `byad` ; anciens participes (`wâsee`).
- Emploi (§71, 71bis) : toujours après le nom ; épithète = accord + article si nom déterminé ;
  attribut = accord sans article. Pluriels d'objets/animaux → accord souvent au **féminin singulier**
  (`le-hwânet mzewwga`).
- **Comparatif / superlatif** (§88, 88bis) : `akbar men`, `asgar men` (invariable) ; plus courant :
  adjectif + `ahsan men`, `aktar men`, `hêr men`, `agall men`, `metl-/kîf-`.
  Superlatif : `b-ez-zâf`, `gâya`, adjectif d'intensité, ou comparatif + nom (`ahsan-najjâr`) ;
  avec article : `le-mhayyar`, `el-madrasa-l-kubra` (f. de `akbar` = `kubra`).

### Numération
- 11-19 (§61) : `hdâš, tnâš, tlâtaš, rbetâš, hmestâš, settâš, sbetâš, tmentâš, tsetâš` ;
  suivis d'un nom **au singulier sans article**, liaison `-en-` : `tmentâš-en-šhar`.
- 20-99 (§85) : `eašrîn, tlâtîn, rabeîn, hemsîn, settîn, sebeîn, tmânîn, tseɛîn` ;
  **unités avant dizaines**, liaison `u-` : `hemsa u-rabeîn yôm` (45 jours).
- 100+ (§90) : `mya`, `mîtîn`, `telt-e-mya` ; `alef`, `alfîn`, `telt-alâf`, puis `hdâš-alef`.
- Ordinaux (§91) : `awwel, tânî, tâlet, râbeɛ, hâmes, sâtes, sâbeɛ, tâmen, tâsee, eâšer` ;
  « dernier » = `tâli` ≠ `tânî` ; `tânawî` = secondaire. Au-delà de 10e → cardinal.
- Heure (§73 notes, §85bis) : `râhé t-imânya gêr-rboe` (8 h moins le quart) ;
  `ela-t-tmânya b-ad-dabt` (à 8 h juste) ; `men-hna ela-hems-e-dqâyeq` (d'ici cinq minutes).

### Relatif et indéfinis
- **Relatif** (§94, 94bis) : `elli` (variantes `li`, `di`), invariable en genre/nombre ;
  sans antécédent = « celui qui » ; pour une chose : `ma` (≠ négation `ma-`) ; `belli` = conjonction « que ».
- **Relative** (§96, 96bis) : pronom de rappel obligatoire quand le relatif est complément —
  après le verbe (objet) : `el-weld elli drabtuh` ; après la préposition : `el-bent elli hrejna meaha` ;
  après le nom (dont) : `el-eummâl elli wlâdhum f-el-jazâir`.
- **Indéfinis** (§99, 99bis) : `kull` (avec article = tout ; sans article = chaque) ;
  `wâhed/wâhda` pronom (« un certain ») ; `kull-wâhed` (chacun) ; `bâed` + collectif/pluriel avec article (certains) ;
  réciprocité `bâedna-bâed`, `bâedhum-bâed`.
- **Expressions indéfinies** (§101, 101bis) : `kull-ši` (tout) ; `ši` après `ma-` (rien) ;
  `hetta-ši`, `hetta-šay`, `šay` ; `hetta-hâd` / `hâd` (personne).

### Exclamation et formules (§104)
`yâ-` (vocatif) ; `ayya-`, `yâ-lâh` (allons) ; `lâ-budda` (il faut) ; `hâ-` + pronom isolé (voici) ;
`yâ-saedi` (quelle chance) ; `yâ-hasra` (hélas).
Formules religieuses relevées dans les textes : `es-salâmu eali-kum` / `wa-ealik es-salâm`,
`men-fadl-ek` / `men-fdal-kum` (s'il vous plaît), `irham wâldikum` (s'il vous plaît, je vous en prie),
`in-šâe-allâh`, `b-esm-ellâh`, `salléw ela-n-nabî` / `sallâ-llâhu elih u-sellem`, `w-allâh` (serment).
**Ces formules sont transcrites telles que le livre les donne ; les adapter au contexte et au registre avant usage.**

## Garde-fous
1. Ne pas mélanger avec le dictionnaire 1910 (`register=belkassem_1910`) ni avec le corpus vidéo contemporain.
2. Ne pas convertir la transcription du livre vers `3 / 7 / ch` sans le signaler explicitement.
3. Ne pas publier les textes (§58…§108) : ils sont **indexés**, pas transcrits.
4. Signaler les formes marquées « à confirmer » dans `notes` plutôt que les affirmer.
5. Valeurs monétaires historiques (`dôro` = 5 centimes, dinar de l'époque) : ne pas transposer.
6. Les emprunts entre crochets (`škâra`, `farrân`, `borgo`, `kettân`, `tâbla`, `zenqa`) sont datés :
   préférer signaler la variante moderne plutôt que les présenter comme le mot courant actuel.
