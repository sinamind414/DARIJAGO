## Tournures récurrentes des dialogues (à valider)
- Salutations : `essalâmu ealay-kum` / `ealay-kum es-salâm` ; `ahlân bi-k` ; `wâš-râk / wâš-hâlek` ; réponse `râni b-hér, el-hamdu-llâh`.
- Santé : `kunt mrêda`, `hâmya u-eayyâna` (fiévreuse et fatiguée), `lâ-bâs`.
- Obligation / nécessité : `lâ-budda` (+ inaccompli), `ilzem`.
- But : `bâš` + inaccompli.
- Futur proche / intention : `râni râyh / râni mâši` + inaccompli.
- Administration : `warqa matbôea` (ordonnance/feuille imprimée), `masrôf et-tbib` (frais médicaux), `el-farmasi` (pharmacie).
